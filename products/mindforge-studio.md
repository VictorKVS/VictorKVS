# MindForge Studio

**Status:** SHOWCASE / PARTIAL PRODUCT IMPLEMENTATION

MindForge Studio is the engineering environment in the MindForge lineage. Current repository evidence shows concrete implementation and test assets, but not yet a fully reproducible MVP acceptance path on a clean host.

## Verified today

- concrete Python implementation exists;
- `core/` contains adapters, agents, knowledge, pipeline, profiles, schemas, templates and web-pipeline modules;
- an executable portrait pipeline entry point exists;
- the repository contains multiple generation, stability, safe-mode, load and resolution test programs;
- the latest visible commit is dated 2026-03-04 and reports partial test success with external runtime dependencies still required.

## Current evidence gaps

- no single canonical quick-start has yet been proven on a clean host;
- several workflows depend on local external AI services;
- historical test counts are not treated as fresh CI evidence;
- legacy and newer execution paths still need one canonical product boundary.

## Promotion gate

Canonical quick start → dependency matrix → clean-host setup → automated core tests → fresh acceptance evidence → documented limitations → architecture map.

## Ecosystem role

**MindForge** is the engineering/MVP-factory lineage. **MindForge Studio** is an inspectable implementation environment inside that lineage. **PX00** remains the protected advanced autonomous engineering-intelligence evolution and is not modified by portfolio normalization. The evidence-backed knowledge layer supports future verification and decision traceability.
